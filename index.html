GET STARTED

연결하고, 실행하고, 확인하세요.

01 · 회로 연결

핀 또는 빵판 구멍을 클릭하고 다른 연결점을 클릭하세요. 같은 행의 A–E, F–J는 각각 연결되어 있습니다. 중앙 홈 양쪽과 전원 레일은 서로 분리됩니다.

02 · 부품 배치

저항·LED는 구멍 두 곳을 클릭합니다. LED는 첫 번째가 A(+), 두 번째가 K(−)입니다. 버튼·LCD는 생성된 모형을 끌어 설치합니다. 모든 다리에 초록색 표시가 나타날 때 놓으면 구멍에 장착됩니다. LCD는 세로로 회전해 빵판 열에 놓으세요.

03 · 코드 실행

setup()과 loop()에 GPIO 스케치를 작성하고 시작을 누르세요. 버튼은 실행 중 누르는 동안 연결됩니다. 핀을 클릭하면 전압을, 부품을 클릭하면 전류를 확인합니다.

04 · 편집과 저장

부품·배선 선택 후 Esc 또는 Delete로 삭제, R로 45° 회전합니다. 배선 연결 도중 Esc는 연결 취소입니다. Ctrl+Z는 되돌리기, Ctrl+S는 저장입니다. 보드 핀 검색은 PC 13처럼 공백을 포함해도 됩니다. 결과를 선택하면 그 물리 핀만 파란 표식과 이름으로 강조됩니다.

코드 문법

int / bool / float 변수, 산술·비교·논리 연산, if / else, while, #define을 지원합니다. 반복문에는 delay()를 넣으세요. 핀 이름은 D13, PA5, A0처럼 씁니다. analogRead는 0~4095, analogWrite는 0~255의 평균 전압 모델입니다.

pinMode(D13, OUTPUT);
digitalWrite(D13, HIGH);
delay(500);

저항·다이오드·LED의 단순 회로 모델, 커패시터의 20 ms RC 충·방전, GPIO를 시뮬레이션합니다. 새 부품 9종은 부품별 실행 예제로 확인할 수 있습니다. 가변저항·스위치·온도·거리는 실행 중 속성에서 조절하세요. HC-SR04는 pulseIn 기반 모델이며 µs 단위 파형과 임의 센서 라이브러리는 지원하지 않습니다. LCD는 16핀 배치·배선 모형이며 화면 제어 명령은 지원하지 않습니다. 실제 ARM CPU 명령, CubeIDE ELF/BIN, HAL 전체, 타이머·UART·I²C·SPI 주변장치, 일반 SPICE 해석은 지원하지 않습니다. USER 버튼은 PC13, 보드 LED는 PA5로 표시합니다.
