GET STARTED
코드를 쓰고, 회로를 연결하고, 실행하세요.
01 · 화면 구성
왼쪽 활동 바에서 탐색기·부품·예제·보드 핀·실행 및 디버그·장치 Docs를 열고, 설정(단축키 포함)은 편집 → 설정 창에서 엽니다. 가운데는 코드 편집기와 회로가 나란히 있고(패널 머리의 ⠿를 끌어 자리를 바꾸거나 ⧉로 새 창에 띄울 수 있습니다), 아래 패널에서 문제·출력·터미널·직렬 모니터·파형·로직 분석기·빌드를 확인합니다. 오른쪽 속성 패널은 선택한 핀·배선·부품의 값과 측정을 보여 줍니다. Ctrl+Shift+P로 모든 명령을, Ctrl+P로 파일을 찾습니다. Ctrl+B 사이드바, Ctrl+J 패널, Ctrl+Alt+B 속성 패널을 접고 펼칩니다.
02 · 회로 연결
핀 또는 빵판 구멍을 클릭하고 다른 연결점을 클릭하면 배선됩니다. 바닥을 클릭하면 꺾임점이 생기고, Backspace는 마지막 점을, 우클릭 또는 Esc는 작성 중인 배선을 취소합니다. 저항·LED 같은 2핀 부품은 구멍 두 곳을 클릭하고, 다핀 부품은 추가한 뒤 끌어서 모든 다리에 초록 표시가 나타날 때 놓습니다. 빵판의 A–E, F–J 행과 전원 레일은 각각 연결됩니다.
03 · 실행 대상
회로 시뮬레이터는 컴파일 없이 HAL C 소스를 해석해 바로 실행합니다. 펌웨어 에뮬레이터는 ARM GCC로 만든 ELF를 Cortex-M4(NUCLEO-F446RE)·Cortex-M3(NUCLEO-F103RB) 명령어 단위로 실행하며 실제 ST HAL·NVIC 선점·DMA·타이머가 가상 빵판과 연결됩니다. STM32 · ARM GCC는 실물 보드에 기록·디버그하고, Windows · C/C++는 PC 프로그램을 빌드합니다. Ctrl+F5 실행, F10 디버그 시작, F9 중단점.
04 · 편집과 저장
Shift+클릭 또는 Shift+드래그로 여러 항목을 선택하고 Ctrl+A 전체 선택, Ctrl+D 복제, Ctrl+C/V 복사·붙여넣기, R 45° 회전, Delete 삭제를 사용합니다. 배선을 더블클릭해 꺾임점을 추가하고 점을 우클릭해 지웁니다. 휠·핀치는 커서 위치를 중심으로 확대합니다. Ctrl+Z 되돌리기, Ctrl+S 저장, Ctrl+F 찾기, Ctrl+R 바꾸기. 작업은 자동 저장되며 프로젝트 폴더 저장은 실패해도 이전 상태로 복구됩니다.
디버그 단축키
Ctrl+F5 실행/계속 · F10 디버그 시작 · F11 한 줄 실행 · Ctrl+F11 함수 안으로 · Shift+F11 함수 밖으로 · F6 일시정지 · Ctrl+F2 디버그 및 실행 중지 · F9 중단점 · Ctrl+Shift+B 빌드. F9를 뺀 실행·보기 명령 키는 편집 → 설정 → 단축키에서 바꿀 수 있습니다. 회로에서 W 배선, V(또는 Esc) 선택.
코드 예시
Pinout & Configuration에서 핀을 활성화하고 HAL 초기화 코드를 생성한 뒤 HAL 함수를 사용하세요. printf는 SWV/USART로, 통신 신호는 로직 분석기에서 비트 단위로 확인합니다.
HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);
printf("PA5 toggled\n");
HAL_Delay(500);
지원 HAL API와 장치별 모델 범위는 README와 docs/HAL-API.md, 펌웨어 에뮬레이터 구조는 docs/architecture/EMULATOR.md를 참고하세요.
