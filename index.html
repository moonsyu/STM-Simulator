GET STARTED
연결하고, 실행하고, 확인하세요.
01 · 회로 연결
핀 또는 빵판 구멍을 클릭하고 다른 연결점을 클릭하세요. 배선이 구멍과 겹치면 배선이 먼저 선택됩니다. 구멍에서 새 배선을 시작하려면 배선 도구(W)를 선택하세요. 같은 행의 A–E, F–J는 각각 연결되어 있습니다. 중앙 홈 양쪽과 전원 레일은 서로 분리됩니다.
02 · 부품 배치
저항·LED는 구멍 두 곳을 클릭합니다. LED는 첫 번째가 A(+), 두 번째가 K(−)입니다. 버튼·LCD는 생성된 모형을 끌어 설치합니다. 모든 다리에 초록색 표시가 나타날 때 놓으면 구멍에 장착됩니다. LCD는 세로로 회전해 빵판 열에 놓으세요. 부품 목록에서 빵판을 추가할 수 있습니다. 추가 빵판의 테두리를 끌면 장착한 부품과 배선도 함께 이동합니다.
03 · 코드 실행
HAL 예제를 선택하면 회로와 코드가 함께 준비됩니다. main.c를 가져오거나 코드를 편집한 뒤 시작을 누르거나 F5를 누르세요. printf 및 UART TX/RX 결과는 로그 탭에서 확인합니다. 버튼은 실행 중 누르는 동안 연결됩니다. 핀을 클릭하면 전압을, 부품을 클릭하면 전류를 확인합니다.
04 · 편집과 저장
부품·배선 선택 후 Esc 또는 Delete로 삭제, R로 45° 회전합니다. Shift+클릭으로 여러 부품·배선을 선택하고 Ctrl+C/V로 복사합니다. 배선을 더블클릭해 꺾임점을 추가하고 점을 끌어 이동하세요. 점 우클릭은 제거입니다. 배선 연결 도중 Esc는 연결 취소입니다. Ctrl+Z는 되돌리기, Ctrl+S는 저장입니다. 보드 핀 검색은 PC 13처럼 공백을 포함해도 됩니다. 결과를 선택하면 그 물리 핀만 파란 표식과 이름으로 강조됩니다.
코드 문법
사용자 함수, 배열·구조체·범위 검사 포인터, if / else, for / while / do, break / continue / return, 비트 연산과 #define을 지원합니다. Pinout에서 핀을 활성화하고 HAL 초기화 후 GPIOA, GPIO_PIN_5 같은 HAL 핀 이름을 사용하세요. HAL_Delay로 대기하고 printf로 결과를 출력합니다. ADC는 12비트이며 파형 탭에서 PWM 계산을 선택합니다.
HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);
printf("PA5 toggled\n");
HAL_Delay(500);
LCD는 4/8비트 명령과 문자·사용자 문자를 지원합니다. HAL UART, I²C, SPI는 전원·배선 기반 통신 모델이며 타이머·EXTI 콜백을 지원합니다. 파형은 최대 12,000개 기록과 CSV 저장을 지원합니다. 실제 ARM 명령·ELF/BIN·레지스터·전체 HAL, 전체 C++ 라이브러리, 정밀 SPICE 해석은 지원하지 않습니다. 통신과 센서의 세부 모델 범위는 README 및 HAL API 문서를 확인하세요.
