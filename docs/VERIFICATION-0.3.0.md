# 검증 기록 — 0.3.0

2026-09-06, Windows x64 / Node.js 24.19.0 / Electron 44.2.0.

## 변경 사항

- 검색 결과에서 선택한 물리 핀 하나를 파란 테두리·핀 이름으로 강조하고 목록에도 선택 표시를 적용했습니다. 같은 GPIO의 나머지 핀 위치는 노란색으로 구분합니다.
- 가변저항, 슬라이드 스위치, RGB LED, 커패시터, 다이오드, 능동 부저, 7세그먼트, TMP36 온도 센서, HC-SR04 초음파 센서의 모형·핀·배선·실행 모델과 부품별 예제를 추가했습니다.
- 실시간 가변저항 위치·스위치·온도·거리 조절, 부저 음향 켜기/끄기, 새 부품의 저장·복원을 지원합니다.

## 자동 검증

`node --test tests/circuit.test.js`: 31개 통과.

기존 22개 검증에 다음을 추가했습니다.

1. 9종 전체 예제의 구멍 정렬, 저장 형식, 잘못된 값 거부.
2. 가변저항의 조절 위치·부하·양 끝점 전압.
3. 슬라이드 스위치의 입력값 유지와 전원 단락 감지.
4. RGB의 세 채널 독립 점등과 직렬 저항 전류.
5. 다이오드 정·역방향과 커패시터 충·방전. 같은 시각의 반복 측정이 충전 시간을 늘리지 않음.
6. 부저의 정·역극성 및 동작 전압.
7. 7세그먼트의 a–g·dp 독립 점등과 공통 음극 연결.
8. TMP36의 온도 전달식, 온도 양 끝값, 전원 없는 상태.
9. 초음파 전원·연결·트리거 폭·타임아웃·한 번만 소비되는 ECHO 결과.

개발용 Electron과 패키징된 `dist/win-unpacked/STM32 Circuit Lab.exe`에서 다음 UI 스크립트를 모두 통과했습니다.

- `scripts/ui-smoke.cjs`: 기존 회로 실행과 IPC 파일 입출력.
- `scripts/editor-smoke.cjs`: 구멍 정렬·45° 회전·10색 배선·Esc 삭제·다핀 배치 등 이전 버전 편집 기능.
- `scripts/parts-smoke.cjs`: 검색 결과의 선택 전환, 부품 9종 생성과 실제 IPC 파일 저장·복원, 가변저항 ADC, 스위치 GPIO, RGB 혼합색, 7세그먼트 8개 점등, RC 동작, 다이오드 전류, 부저 시각 상태와 WebAudio 그래프 생성, 온도와 거리 조절 후 실제 출력값.

브라우저 스크립트 오류는 없었습니다. 부저는 음향 그래프 생성과 동작 조건을 검증했으며 사용자의 스피커에서 소리가 들리는지 청취 검증한 것은 아닙니다.

결과와 화면은 `test-results/`에 기록합니다. 원본 0.1.0/0.2.0 EXE는 보존합니다.

## 모델 범위

학습용 모델이며 일반 SPICE나 실제 STM32 CPU 에뮬레이터가 아닙니다. 커패시터는 20 ms 후진 오일러 RC 모델입니다. TMP36은 전압 전달식, HC-SR04는 TRIG와 `pulseIn(HIGH)` 기반 모델입니다. µs 단위 실행·임의 펄스 측정·센서 노이즈·재질 반사는 지원하지 않으며, ECHO와 입력은 같은 도선 노드여야 합니다. LCD의 문자열 출력은 기존과 같이 미지원입니다. 세부 수치와 참고 문서는 README 및 부품 속성 안내에 기재했습니다.
