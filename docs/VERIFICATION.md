# 현재 검증 기록 — 0.9.0

2026-09-10, Windows x64, Node.js 24.18.0, Electron 44.2.0, Playwright 1.58.2.

## 변경

- 배선이 빵판 구멍과 겹치면 선택 모드에서 배선을 먼저 선택한다. 배선 도구(W)와 연결 중에는 구멍에 접근할 수 있다.
- Ctrl+F5로 시뮬레이션을 시작·정지한다. 코드 편집 중에도 동작하며 페이지 새로고침, 누른 키 반복, 대화상자 뒤의 실행을 방지한다.
- 상단바를 아이보리 배경·부드러운 초록색·둥근 입력과 버튼으로 변경하고 S 아이콘을 제거했다. SVG 보드의 모델명만 제거하고 실제 핀·헤더·USER/RESET·LD2 표시는 유지한다.
- 부품 목록에 400홀 빵판을 추가했다. 각 빵판의 행과 레일은 독립되며 부품 장착·배선·이동·회전·삭제·저장/복원을 지원한다. 기본 빵판 외 최대 8개를 추가할 수 있다.
- 보드명·MCU 검색과 보드 선택 창을 추가했다. 현재 NUCLEO-F446RE 한 종류만 제공한다.
- 기본 상태에서 회로·코드·핀·소스·계산 설정·이름이 변경되면 보드 초기화 경고를 표시한다. 파일을 저장해도 경고가 유지되며 취소/Escape는 작업을 보존한다. Undo로 기본 상태로 돌아오면 경고하지 않는다.
