# 현재 검증 기록 — 0.9.0

2026-09-10, Windows x64, Node.js 24.18.0, Electron 44.2.0, Playwright 1.58.2.

## 변경

- 배선이 빵판 구멍과 겹치면 선택 모드에서 배선을 먼저 선택한다. 배선 도구(W)와 연결 중에는 구멍에 접근할 수 있다.
- Ctrl+F5로 시뮬레이션을 시작·정지한다. 코드 편집 중에도 동작하며 페이지 새로고침, 누른 키 반복, 대화상자 뒤의 실행을 방지한다.
- 상단바를 아이보리 배경·부드러운 초록색·둥근 입력과 버튼으로 변경했다. SVG 보드의 모델명만 제거하고 실제 핀·헤더·USER/RESET·LD2 표시는 유지한다.
- 부품 목록에 400홀 빵판을 추가했다. 각 빵판의 행과 레일은 독립되며 부품 장착·배선·이동·회전·삭제·저장/복원을 지원한다. 기본 빵판 외 최대 8개를 추가할 수 있다.
- 보드명·MCU 검색과 보드 선택 창을 추가했다. 현재 NUCLEO-F446RE 한 종류만 제공한다.
- 기본 상태에서 회로·코드·핀·소스·계산 설정·이름이 변경되면 보드 초기화 경고를 표시한다. 파일을 저장해도 경고가 유지되며 취소/Escape는 작업을 보존한다. Undo로 기본 상태로 돌아오면 경고하지 않는다.

## 완료한 검증

- npm test: **120개 통과**, 실패 없음. 신규 보드·빵판 모델 9개와 기존 회로·HAL·빌드 정리 검증 111개를 포함한다.
- Electron UI **8개 스크립트 통과**: ui/editor/parts/features/hal/layout-serial/hal-examples/boards. 추가 빵판에 맞춰 부품 수를 17종으로 갱신했다.
- 실제 겹친 구멍 클릭으로 배선 선택 및 W 도구를 통한 구멍 연결을 검사했다. 편집기에서 Ctrl+F5 시작/정지와 원문 보존을 확인했다.
- 추가 빵판에 저항을 장착하고 보드의 3.3 V/GND를 연결해 10 mA를 확인했다. 빵판 이동·45° 회전 시 부품과 배선 유지, 파일 저장/다시 열기, 삭제 시 연결 해제와 Undo 전체 복원을 검사했다.
- 모델 검증에서 겹친 빵판끼리의 전기적 절연, 회전한 구멍 좌표, 점유 검사, 잘못된 연결 ID 거부, 다른 지지대에 걸친 부품의 부분 연결 해제를 확인했다.
- 1120×760 최소 창과 기본 창에서 상단바·보드 검색·변경 경고·추가 빵판 화면을 직접 확인했다. 렌더러 오류 없음.

## 배포 검증 상태

소스 검증 후 0.9.0 Windows EXE를 빌드 중이다. 패키지와 단일 EXE 실행, GitHub Releases 게시, 이전 빌드 정리 결과는 완료 후 이 문서에 갱신한다.

## 범위

지원 HAL API를 회로에 연결하는 소스 인터프리터이며 전체 ST 드라이버·ARM/ELF/BIN 실행기는 아니다. 새 보드 종류는 추가하지 않았다. 테스트는 사용자 자동 저장과 분리된 프로필을 사용한다.
