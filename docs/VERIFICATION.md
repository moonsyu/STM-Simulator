# 검증 기록 — 0.1.0

검증일: 2026-09-06. Windows x64, Node.js 24.19.0, Electron 44.2.0.

## 회로 및 인터프리터

`node --test tests/circuit.test.js`: 17개 통과.

- 보드의 108개 물리 핀, 중복 없는 400개 빵판 구멍과 좌표
- 빵판 5개 구멍 단위 연결, 중앙 홈 분리, 네 전원 레일의 독립성과 연속성
- Arduino / Morpho 핀 이름의 같은 노드 연결
- 저항과 LED의 순방향 전압을 반영한 전류, LOW 출력 시 소등
- LED 역방향 및 회로 단선 시 소등
- 전원 직접 단락 시 계산 중단, GPIO 단락 시 과전류 경고
- 외부 버튼 입력과 풀업 동작
- 10 kΩ + 10 kΩ 분압 결과 약 1.65 V, 저항 전력
- 부유 노드는 0 V로 단정하지 않고 측정값 없음 처리
- 부품 단자와 빵판 연결점 좌표 일치
- 프로젝트 직렬화·역직렬화, 잘못된 연결점·부품 값 거부
- 시간 진행에 따른 스케치 실행, 버튼과 회로 해석 통합, ADC Serial 출력
- 문법 오류와 지원하지 않는 함수 감지, 무한 반복 실행 한도
- 변수, define, 조건식, PWM 평균 전압

## 실제 데스크톱 화면 동작

`scripts/ui-smoke.cjs`를 개발용 Electron과 `dist/win-unpacked/STM32 Circuit Lab.exe`에서 각각 실행해 통과했습니다.

- 초기 화면의 구멍 개수와 연결점 확인
- 실제 실행 버튼으로 LED 전류 HIGH / LOW 교대 확인
- 연결점 클릭으로 배선 추가, 실행 취소 및 재실행
- 두 구멍을 지정해 LED 장착, 부품 삭제
- 외부 버튼을 마우스로 누르고 떼는 동안 회로 전류 변화
- 분압 예제의 ADC 결과를 실행 모니터에서 확인
- 종료되지 않는 스케치가 실행 한도로 중단되고 화면이 응답함
- 파일 선택창의 경로만 테스트 경로로 대체하고, 실제 Electron IPC와 파일 입출력으로 회로 저장·불러오기 확인
- renderer JavaScript 오류 없음

재현 결과 JSON과 화면 캡처는 `test-results/`에 기록됩니다. 해당 폴더는 임시 테스트 산출물로 Git 추적에서 제외했습니다.

## 최종 단일 EXE

`scripts/portable-smoke.cjs`로 `dist/STM32-Circuit-Lab-0.1.0-win-x64.exe`를 직접 실행했습니다. 임시 디렉터리로 앱 본체가 추출되고 창이 열리는 것을 확인한 뒤, 400개 연결 구멍과 LED 회로 실행을 검증했습니다. 통과 결과는 `test-results/portable-smoke.json`, 실제 실행 화면은 `docs/app-preview.png`입니다.

- 파일 크기: 100,099,891 bytes
- SHA-256: `D0E32EE7086B1433D4C245DAF29AF8EC41E1CAD935E02D86DF1EAB79CA785857`

단일 EXE는 별도 런처를 거치므로 일반 `_electron.launch` 테스트 연결 대신 Chromium 디버깅 프로토콜로 실제 창에 연결했습니다. 최종 파일 실행과 회로 동작은 확인했으며, 전체 편집·파일 입출력 검증은 동일 앱 본체인 `win-unpacked` 실행파일에서 수행했습니다.

## 해석 범위

이 결과는 구현된 학습용 DC/GPIO 모델의 검증입니다. 실제 STM32 CPU, ELF/BIN 펌웨어, 전체 HAL 또는 실제 하드웨어 전기 특성과의 동등성을 검증한 것이 아닙니다. 모델 한계는 프로젝트 README와 앱 도움말에 표시했습니다.
