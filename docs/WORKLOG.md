## 2026-10-21 · 0.29.0 UI 다듬기와 기능 점검

- 요청: 전체 기능 검증과 더 세련된 UI/UX.
- 점검: 단위·인터프리터·에뮬레이터·펌웨어 테스트(676개 중 674 통과, 실패 2개는 로컬 심볼릭 링크 권한), 실제 앱 E2E 20개(19 통과·1 건너뜀), HAL 예제 127개 실행 감사(오류 0, 출력 변화 없음). 사이드바 보기·하단 패널·설정·명령 팔레트·메뉴를 Dark/White 화면 캡처로 확인했다.
- 수정한 결함: 예제 57개의 `#include <stdio.h>` 중복, 회로 키보드 안내 문구 반복, 정지 후 WS2812 속성의 잘못된 전원 경고.
- 디자인: 표면 3단계 색과 모드별 파란 강조색(모든 조합 WCAG AA), 활동 바 둥근 선택 표시, 메뉴·팔레트·대화상자 모서리와 그림자, 하단 탭 2px 밑줄, 알약형 태그·버튼, 직렬 모니터 빈 상태 안내, 속성 패널 부품 종류 배지와 글자형 삭제 버튼.
- 발견: 사용자가 PC를 쓰는 동안 로컬 E2E 창이 실제 키 입력(Ctrl+C)을 받아 로그에 "부품 복사"가 찍혔다. 앱 결함이 아니다. 사용자 요청으로 작업 중에는 테스트 창을 비활성으로 띄워 맨 뒤로 보내는 임시 변경(`desktop/main.cjs`, `tests/e2e/harness.mjs`)을 쓰고, 끝난 뒤 되돌렸다(커밋하지 않음).
- 커밋: `36856bb` UI 다듬기와 기능 점검 수정, `90504af` 0.29.0 버전·HANDOFF, 검증 기록 커밋. [Release v0.29.0](https://github.com/moonsyu/STM-Simulator/releases/tag/v0.29.0), [CI 39524337726](https://github.com/moonsyu/STM-Simulator/actions/runs/39524337726) 성공. latest 지정, 태그·커밋 일치, 5자산과 EXE·ZIP 해시(ZIP 안 EXE 포함) 확인.
- 남은 사항: 작은 창 크기·고배율 디스플레이에서의 디자인은 따로 확인하지 않았다.

## 2026-10-21 · 0.28.0 코드 정렬 배포와 예제 결과 표시

- 요청: redesign 브랜치의 코드 정렬 기능 검증 후 배포, 결과를 볼 수 없는 HAL 예제(특히 WS2812 RGB) 수정.
- 코드 정렬 검증: 단위 테스트, E2E(`}` 입력 블록 정렬·Alt+Shift+F), 경계 사례(구조체/배열 초기화, 중첩 중괄호 없는 본문, 여러 줄 호출, `#ifdef`). 모든 예제에서 토큰 불변·멱등.
- 예제 감사: 127개를 3초씩 실행해 출력·회로·속성 패널을 확인했다. 주소지정 RGB 3종은 거의 검은 색 하나만 보내 꺼진 것처럼 보였고 속성 패널이 비어 있었다. 예제가 빨강→초록→파랑→흰색을 보내고 로그를 남기며, LED가 받은 색으로 켜지고 속성 패널에 G/R/B를 보이도록 고쳤다. ULN2003·인코더 소자·RS485·I²C LCD·모터 HAT의 속성 문구도 실제 동작에 맞췄다.

- 커밋: `536dedd` 0.28.0, `f7ceea6` 검증 기록. [Release v0.28.0](https://github.com/moonsyu/STM-Simulator/releases/tag/v0.28.0), [CI 39520981687](https://github.com/moonsyu/STM-Simulator/actions/runs/39520981687) 성공, 공개 자산 해시 확인.
