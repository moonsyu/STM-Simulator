- 기존 선택 Esc 삭제, 사용자 프로젝트 저장·복구, 단일 보드 방식, DOM 셀렉터, 코드 전용 colorscheme를 유지합니다.
- 문서의 줌 예제 6000 상한은 무제한 캔버스 불변식과 충돌하므로 추가하지 않았습니다. 좌표/계산의 finite 검사는 유지합니다.
- 검토 중 그룹 드래그→Ctrl+D→후속 이동이 복제본을 잃을 수 있음을 찾아 활성 drag 동안 새 선택/복제 단축키를 차단했습니다. 별도 회귀 검사로 보존합니다.
- 신규 실행 상태 대비 검사에서 기존 disabled 보드 F4 배지가 저대비임을 확인해 배경/글자 테마쌍을 맞췄습니다. 최초 실패도 evidence에 남겼습니다.
- 성능 개선은 DOM 재생성 방지로 검증했습니다. 프레임 시간 개선 비율은 측정하지 않았습니다. 실제 STM32 하드웨어 검증이 아닙니다.
