# Tinkercad 참고 적용 · 반복 검수 계획

2026-10-19. 기준 main040e755 / 공개0.24.0. 사용자의 활성 목표 전체를 유지합니다.

## 요구사항과 승인 근거

- 사용자 첨부 회로 이미지와 Codex 브라우저의 Tinkercad `초음파센서 lcd2줄` 화면을 직접 확인했습니다. 해당 프로젝트를 편집하거나 자산을 복제하지 않고 부품 식별성·정확한 핀 접점·얇은 둥근 배선·부품 목록 표현을 참고합니다.
- 사용자가 그 표현을 적용하고 UI/UX·디자인·기능의 문제를 수정하도록 명시했습니다. 이 지시를 기존 IDE/시뮬레이터 구조 안에서의 개선 방향 승인으로 기록합니다. 단일 STM32 보드, 기존 핀맵/장치114종/파일/Docs/HAL 기능을 보존합니다. 새 보드나 CPU 에뮬레이터로 범위를 바꾸지 않습니다.
- 착수 전 편집 가능한 시안: `docs/ui/mockups/src/tinkercad-workbench.html`. 기존 패널 도킹·크기 조절과 ID를 보존하며 보조 도구는 좁은 폭에서 접거나 묶습니다.

## 진행 방식

1. 브라우저/이미지/현재 코드·감사 자료를 대조하고 재현 가능한 결함을 이슈로 등록합니다.
2. 파일 소유 범위를 나눠 구현하고 각 변경의 동작·실제 화면을 검증합니다.
3. 실패를 숨기지 않고 로그에 남긴 뒤 원인 수정과 해당 회귀를 실행합니다. 사용자 요청에 따라 필요한 검수 라운드를 반복합니다.
4. 제품 버전을 올리면 moonsyu 계정으로 소스와 새 Release를 함께 게시합니다. 기존 태그/자산은 덮어쓰지 않습니다.
5. 공개 STM-Simulator.exe와 ZIP의 실행, 저장·복원, 실제 자동 업데이트를 확인하고 최종 요구사항별 증거를 감사합니다.

보안/데이터: 사용자 Tinkercad 회로는 읽기 전용 참고. 사용자 앱/프로필은 건드리지 않고 독립 프로필 사용. 코드 위치는 내부 보고서에 저장합니다. 확인되지 않은 항목을 완료로 간주하지 않습니다.
