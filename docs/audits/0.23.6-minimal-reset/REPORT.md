# 코드 초기화 생성 코드 전수 정리

기준: 0.23.6. 사용자 요청은 초기화 후 남는 미사용 코드 제거. 현재 사용자 프로필은 조작하지 않으며 별도 회로·숨김 Electron 프로필·파일 로그로 검사한다.

| 항목 | 처리 |
|---|---|
| LD2 등 미사용 핀 매크로 | 0.23.5 제거 유지 |
| stdio.h, __io_putchar, ITM_SendChar, printf 안내 | 초기화에서 제거 |
| 비어 있는 GPIO/타이머/UART 콜백 | 제거; 필요한 콜백은 사용자가 작성 |
| HAL_Delay, 자동 토글/송신, 타이머 시작 예제 | 제거 |
| 빈 MX_GPIO_Init 및 선언/호출 | 활성 핀·NVIC가 모두 없으면 제거 |
| GPIO_InitStruct | 실제 핀 초기화가 없으면 제거 |
| Reset/Reserved 핀용 GPIO 포트 클록 | 제거 |
| 입력/아날로그/EXTI의 미사용 Speed 대입 | 제거 |
| 스케치 delay, 호스트 stdio.h | 제거 |
| HAL_Init, SystemClock_Config, Error_Handler | 호출과 오류 처리에서 실제 사용하므로 유지 |
| 활성 핀 초기 출력, NVIC, 주변장치 핸들/설정 | 현재 보드 설정을 보존하기 위해 유지 |
| 사용자 보조 파일 | 초기화 대상이 main이므로 보존; 임의 삭제하지 않음 |

생성 결과에서 패턴 삭제하는 기존 방식을 초기화 전용 생성 옵션으로 교체했다. 빈 main의 유휴 처리를 지원하며 타이머/EXTI 이벤트와 디버그 일시정지·단계 실행을 검사한다. 내부 함수의 무한 반복은 기존 실행 한도 오류를 유지한다.

추가 발견: 초기화는 Docs 소유 정보를 지우므로 보드·빵판·버튼 예제의 보조 부품을 재식별하지 못했다. 기존 GPIO 설정과 배선 연결을 사용하여 재사용하고, 기존 핀 라벨을 보존하며 새 라벨 충돌을 방지한다.

## 검증 범위

- 120개 HAL 예제 + 빈 회로 + 주변장치/핀 경계 조건 7개 = 128개 초기화.
- 실제 ST HAL/CMSIS + ARM GCC: 초기화 결과 128개 컴파일·링크 통과. 미사용 변수/함수/매개변수 경고를 오류로 처리.
- 초기화된 코드의 무출력·비활성 타이머·오류 없음, 설정/회로/사용자 파일 보존 검사.
- 장치 114개: Docs 적용 → 초기화 → Docs 재적용 → 입력 변화/LED/모터/표시/통신별 동작 판정.
- 독립 Electron: 초기화 버튼/취소/undo/실행 중 제한, 128개 실제 초기화·실행 및 파일 진단.
- 단위 322개, 초기화 모델 128개, 장치 재적용 114개, 회로 보존 114개, Electron 기본 동작 14개 통과. Electron 전수 초기화 128개 통과. Windows CI·공개 배포 검증 완료.

실행 시간: DHT/DS18B20은 두 차례 입력 변경 이후 변환 결과까지 기다리도록 5.5초, 나머지 장치는 3.5초. 실행 로그는 시뮬레이터 관측값이며 실물 보드 측정이 아니다.

코드 위치는 별도 `FIX-LOCATIONS.md`에 기록한다.
