2026-10-19. 사용자 요청: 빠진 PIN 옵션을 실제 설정 화면에서 변경하고 코드 적용·실행까지 검사하며, 발견한 문제를 수정하고 최신 로그를 구버전 기록과 구분한다.

## 검사 행렬

1. 접근 가능한 GPIO 50개의 용도 선택 370항목을 실제 화면에서 확인한다. 선택만 확인한 항목과 코드 생성·실행한 항목은 별도로 집계한다.
2. Reset/Input/Output/Analog/Reserved × Pull 3종 × 초기 출력 2종의 30개 설정을 전체 GPIO에 적용한다. 생성 HAL과 실제 실행에서 초기 출력/입력 읽기/핀 활성 상태를 확인한다.
3. EXTI 7개 IRQ 그룹의 대표 핀에서 에지 3종 × Pull 3종 × 초기 출력 2종 × 우선순위 16종의 288개 프로젝트 조합(2,016개 핀 설정)을 실제 UI로 설정한다. 에지별 콜백, 차단·재개와 우선순위를 실행에서 확인한다.
4. 사용자 라벨, 값의 경계/빈값/범위 오류, 취소·설정 적용·코드 생성·핀 전환·저장/복원을 확인한다.
5. 실제 동시 pending IRQ에서 콜백이 NVIC/global mask/다른 IRQ 우선순위를 변경하는 경우를 확인한다.

검토 후 추가한 범위: Analog의 내부 Pull/디지털 입력 동작을 RM0390과 대조하고, 외부 전원 0.33/1.65/3.0V에 대한 ADC 측정 보존을 실제 UI 3시나리오로 검사한다. EXTI 활성 288프로젝트는 IRQ별 우선순위를 순환 배정해 설정값뿐 아니라 동시 콜백의 전달 순서도 판정한다. 비활성 18프로젝트를 포함한 최종 계획은 validation19 + 용도선택1 + GPIO30 + EXTI306 + 콜백변경3 + ADC3 = 362시나리오이다.

## 판정 근거

- 실제 select/fill/click → 설정 적용/코드 생성 → 생성된 코드의 핀/풀/에지/초기값/IRQ 값 → 실행·진단 로그를 연결한다.
- 자동 생성 GPIO 초기화는 보존하고, 관측을 위한 사용자 영역 출력/콜백 코드를 구분한다.
- 모든 핀 간 주변장치 배치의 임의 조합이나 Cortex-M 명령어·중첩 선점을 전수검사했다고 주장하지 않는다. 현재 제공되는 PIN 옵션과 HAL 실행 모델의 검사 범위를 기록한다.
- 최종 결과에 검사 수·실패/수정/재검사·미검사 범위·실제 버전·증거 파일 해시를 남긴다.
