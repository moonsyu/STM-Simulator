# 장치 Docs와 예제 적용

회로에서 부품·STM 보드·기본/추가 빵판을 선택하고 코드 패널의 **장치 Docs** 탭을 연다. Docs가 열린 동안 다른 장치를 선택하면 해당 문서로 바뀐다.

## 제공 내용

- 현재 구현된 **35종 부품**, NUCLEO-F446RE 및 기본 빵판의 개요·동작·접점별 배선표.
- 해당 장치의 HAL 호출 목록, 설명, 호출 예시와 완성된 C 예제.
- GPIO IDR/BSRR, ADC SQR3/CR2/SR/DR, TIM CNT/CCR, UART SR/DR, I2C SR1, SPI SR 등 장치와 연결된 레지스터 예제.
- HAL 전체 예제는 39개다. 기존 예제에 LCD 1602, 가변저항, 슬라이드 스위치, RGB LED, 다이오드, 능동 부저, 7세그먼트를 추가했다. 저항은 ADC 분압, 커패시터는 PWM RC 필터, DC 모터/전원은 L298N 회로, 빵판은 LED 회로로 학습한다.

## 적용과 배선 보완

**HAL 예제 + 핀·배선 보완** 또는 함수별 **이 함수 포함 예제 적용**을 누른다. 함수별 버튼도 초기화·버퍼·보조 함수·인터럽트 등 실행에 필요한 장치 예제 전체를 포함한다. 같은 장치에서 다른 함수를 선택해도 중복 코드를 누적하지 않는다.

선택한 부품의 ID·위치·회전·크기·환경 설정은 유지한다. 필요한 직렬 저항·분압 저항·드라이버·전원을 추가하고 사용 가능한 핀/주변 장치를 활성화한다. 기존에 올바르게 연결한 핀과 배선은 재사용한다. 다른 장치가 사용하는 핀은 피하고 타이머가 점유되어 있으면 지원하는 다른 타이머로 배정한다. I2C 주소와 UART 보드레이트는 선택 부품 설정을 따른다. 공유 버스의 통신 설정이 충돌하거나 핀이 부족하면 적용 전에 오류를 표시한다.

전원/GPIO 오접속은 선택 장치 주변의 선이나 장착 접점을 분리해 보완한다. 별도의 사용자 회로를 제거하지 않는다. 공유 빵판망의 단락을 선택 장치 주변에서 해결할 수 없으면 변경 전체를 취소한다. **Ctrl+Z** 또는 실행 취소로 코드·핀·배선을 함께 되돌린다.

## 현재 코드와의 결합

`main.c`와 사용자 소스는 유지한다. `stm_device_docs.c/.h`에 장치별 보조 함수를 만들고 `main`의 초기화와 반복문에 `STM_Devices_Init()` / `STM_Devices_Step()`을 연결한다. 필요하면 기존 HAL 콜백에 디스패처 호출을 추가한다. `main`과 블록으로 된 실행 루프가 없는 소스는 먼저 해당 구조를 작성해야 한다. 사용하지 않은 생성기의 기본 500 ms 대기만 제거하며 사용자 반복문 로직은 유지한다.

자동 생성한 두 파일을 직접 수정하면 재적용 시 덮어쓰지 않는다. 수정 내용을 별도 사용자 파일로 옮기고 생성 파일을 제거한 후 다시 적용할 수 있다. 여러 장치 예제는 순차 실행되므로 각 예제와 사용자 코드의 `HAL_Delay`가 전체 응답 주기에 영향을 준다. 초음파처럼 빠른 폴링이 필요한 코드에 긴 사용자 지연이 있으면 사용자가 주기를 조정해야 한다.

## Bare-metal 범위

레지스터 버튼은 **ARM GCC** 대상으로 전환한다. 선택한 동작을 CMSIS 레지스터 접근 코드로 바꾸며, 핀·주변 장치 초기화와 시간 대기는 기존 HAL 코드를 사용한다. 완전히 HAL을 제거한 펌웨어 템플릿이 아니다. SPI/I2C 항목은 상태 레지스터 관찰 예제이며 장치 프로토콜 전체의 레지스터 드라이버가 아니다. ARM용 컴파일·링크는 검증하지만 실제 보드 동작은 별도 확인해야 한다. 회로의 HAL 인터프리터는 직접 레지스터 접근을 실행하지 않는다.

참고: [ST HAL 드라이버](https://github.com/STMicroelectronics/stm32f4xx-hal-driver/tree/master/Inc), [STM32F446 CMSIS 정의](https://github.com/STMicroelectronics/cmsis-device-f4/blob/master/Include/stm32f446xx.h). 예제는 이 앱의 독립 구현이며 ST SDK는 사용자 개발 도구 경로에서 사용한다.
