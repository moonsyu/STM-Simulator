# STM Simulator 0.23.2

- DS18B20 온도와 SD 카드 응답이 main에 삽입된 코드에서 0으로 바뀌던 오류 수정.
- 2핀 순간 버튼·KY-004 3핀 버튼의 입력/접지 자동 배선 수정.
- 인코더·KY-040 Docs를 TIM 하드웨어 계수 예제로 변경하여 main 대기 중 회전 감지 누락 수정.
- 커패시터 3종의 PWM_Init 카드가 PWM 모드로 초기화되도록 수정.
- TFT 두 종류의 큰 화면 상태가 로그 한도를 넘지 않도록 전체 데이터 해시·표본 기록. 렌더러 IPC 전달도 검증.

코드는 계속 main.c에 직접 삽입하며 추가 함수/파일을 만들지 않습니다. 이미 적용한 구버전 예제는 장치 Docs에서 재적용해야 수정된 코드·배선이 반영됩니다. 직접 편집한 관리 영역은 보호됩니다.

검증 범위와 장치별 실제 동작 로그 판정은 [재검증 보고서](../audits/0.23.2-device-docs/REPORT.md)에 기록합니다. 직접 레지스터 코드는 HAL 실행기의 실행 대상이 아닙니다.

배포 실행 파일명은 `STM-Simulator.exe`입니다. Windows 전체 CI 통과 후 EXE, ZIP, SHA256.txt, BUILD-INFO.json, update-manifest.json을 함께 게시합니다.
