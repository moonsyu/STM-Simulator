# STM Simulator 0.25.2

HAL 예제와 장치 Docs 적용 시 예제의 모든 부품을 빵판 위에 배치하고, 빵판 연결 행을 경유해 배선합니다.

- 부품 다리와 점퍼는 서로 다른 구멍을 사용합니다. 다른 신호가 같은 행에서 합선되지 않도록 연결을 구분합니다.
- 부품 몸체·다른 접점을 가리지 않도록 배치와 배선 경로를 조정합니다. 공간이 부족하면 빵판을 추가하고 전체 회로를 화면에 맞춥니다.
- 3.3 V·5 V·GND 레일을 분리하며 이미 다른 용도로 쓰는 레일은 유지합니다. MCU 크기와 위치를 변경한 경우도 배치에 반영합니다.
- 새 프로젝트의 예제 템플릿과 타이머 루프백 예제에도 동일한 규칙을 적용합니다. USART2 내장 터미널은 별도 UART 부품 없이 동작합니다.
- 물리 변형 버튼과 추가 접점의 빵판 장착 정보를 회로 계산 모델에 전달하도록 수정했습니다.
- 재적용, 단선 복구, 여러 장치 동시 적용과 사용자 코드·무관한 배선 보존을 검사합니다. 기존 회로에 새 배치 규칙을 적용하려면 장치 Docs에서 예제를 다시 적용하세요. Ctrl+Z로 되돌릴 수 있습니다.

검사 범위와 실행 로그는 [빵판 배치 검사 기록](../audits/0.25.2-breadboard/REPORT.md)에 기록합니다. 학습용 회로 모델 검사이며 실물 MCU 실행 검사는 아닙니다.

배포 파일명은 **STM-Simulator.exe**입니다. 같은 Release의 ZIP, SHA256.txt, BUILD-INFO.json, update-manifest.json을 함께 제공합니다.
