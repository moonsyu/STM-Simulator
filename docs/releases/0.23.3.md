# STM Simulator 0.23.3

- **기존 HAL Docs 수정**: 자동 배선된 GPIO·타이머·I²C 주소와 클록 설정을 코드 미리보기에도 반영합니다. PIR 입력의 시작 상태를 가짜 이벤트로 표시하지 않고 설정한 에지 조건을 유지합니다.
- **스테퍼·L298N 자동 배선 수정**: 원래 핀이 사용 중일 때 여러 포트로 재배선된 GPIO 비트 마스크와 동적 위상 출력도 정확히 갱신합니다.
- **코드 초기화**: 코드 패널에서 main 코드만 기본 상태로 되돌립니다. 회로·배선·핀 설정·보조 파일은 유지하며 취소/Esc/되돌리기를 지원합니다. 실행 중에는 비활성화됩니다.

검증: 기존 HAL 원본 40개, 기존 장치/보드 Docs 36개, 개별 HAL 카드 308개, 단선 연결 복구 204개, 단위 검사 309개, ARM GCC 링크 46개. 별도 Electron에서 초기화·재적용·LED 소등/점등·포트 재할당 모터 동작을 파일 로그로 검사했습니다. 실물 STM32 실행 검증은 아닙니다.

다운로드 파일명은 **STM-Simulator.exe**로 유지합니다. ZIP과 SHA256.txt, BUILD-INFO.json, update-manifest.json을 함께 제공합니다. 기존 프로젝트의 Docs 코드에는 자동으로 덮어쓰지 않으므로 해당 장치 예제를 다시 적용해 주세요. 전체 기본 코드로 돌아가려면 새 코드 초기화 기능을 사용하세요.
