# STM Simulator 0.23.5

- 코드 초기화 후 사용하지 않는 `LD2_Pin`·`LD2_GPIO_Port` 정의가 다시 생기는 문제를 수정했습니다.
- HAL 코드 생성과 새 프로젝트도 실제 GPIO 포트/핀 상수를 사용하며 불필요한 별칭을 생성하지 않습니다. Pinout의 라벨·설정과 기존 사용자 헤더는 유지합니다.
- 배포 파일명은 `STM-Simulator.exe`입니다.

검증: 단위/모델 314개, 별칭 없는 ARM 빌드 122개, 개발/공개 EXE 초기화·재적용 14개 검사 통과. 전체 Windows CI와 5개 배포 자산·해시·최신 릴리스 선택을 확인했습니다. 업데이트 후 코드 초기화를 한 번 실행하면 기존 main.c의 불필요한 정의가 제거됩니다.
