# STM Simulator 0.23.7

- 다크(`Dark`) 및 화이트(`White`) 테마 전반의 UI 컬러 팔레트와 표면 대비를 정돈해 장시간 학습·편집 가독성을 높였습니다.
- 상단바, IDE 툴바, 도킹 패널 헤더 및 리사이저, 부품 라이브러리 카드, 회로 캔버스 크롬, 하단 실행 모니터 탭의 타이포그래피와 여백·테두리 반경을 일관되게 다듬었습니다.
- Pinout & Configuration 대화상자, 장치 Docs 패널, 부품 미리보기 팝오버의 시각적 계층과 포커스/선택 강조 표시를 개선했습니다.
- 화면 외관 전환 시 코드 편집기 테마 독립성과 1024×640 소형 화면 레이아웃 호환성을 그대로 유지합니다.
- 배포 실행 파일명은 `STM-Simulator.exe`입니다.

검증: 단위 테스트 322개, 다크/화이트 52개 UI 상태 명암비(WCAG AA) 검사, 외관·무한 캔버스·반응형 레이아웃 검사 통과.
