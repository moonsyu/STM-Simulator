# STM Simulator 0.23.6

- 코드 초기화에서 미사용 헤더, 출력 보조 함수, 빈 인터럽트 콜백, 자동 실행 예제와 임의의 지연을 제거했습니다.
- 설정에 필요하지 않은 GPIO 함수·구조체·포트 클록을 생성하지 않습니다. 활성 핀과 주변장치의 초기화는 보존합니다.
- 비어 있는 main 반복문에서도 시간·인터럽트·디버그가 정상 진행되도록 수정했습니다.
- 초기화 후 보드·버튼 Docs 예제를 다시 적용할 때 기존 부품을 중복 생성하거나 핀 라벨이 충돌하던 문제를 수정했습니다.
- 업데이트 후 **코드 초기화**를 실행하면 적용됩니다. 회로·배선·핀 설정·사용자가 추가한 보조 파일은 유지합니다.
- 배포 실행 파일명은 `STM-Simulator.exe`입니다.

검증: 단위 322개, ARM 빌드·개발/공개 EXE 초기화 128개, 장치 Docs 재적용 동작·회로 보존 114개 통과. Windows 전체 CI와 공개 배포 자산 5개·해시·최신 릴리스 선택을 확인했습니다.
