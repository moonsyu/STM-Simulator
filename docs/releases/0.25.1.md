# STM Simulator 0.25.1

PIN 설정을 편집하거나 여러 IRQ가 대기하는 상황에서 잘못 저장·실행되던 동작을 수정했습니다.

- 타이머 모드 변경과 실패한 핀 용도 배정에서 입력 중 라벨·옵션을 보존합니다.
- NVIC 우선순위, 타이머 PSC/ARR/CCR의 빈 입력을 유효한 0과 구분합니다. 잘못된 PWM CCR 입력이 모드 변경으로 숨지 않도록 전환을 차단합니다.
- IRQ 콜백에서 다른 IRQ 또는 전체 IRQ를 차단하거나 우선순위를 변경하면 다음 콜백 실행에 즉시 반영합니다. 차단된 pending IRQ는 재개할 때 처리합니다.
- Analog/ADC 핀에서 내부 Pull과 디지털 입력을 비활성화하고, 외부 전압과 ADC 측정 경로는 유지합니다.
- 실제 PIN 설정·HAL 적용·실행 및 여러 장치 Docs 적용·재적용·저장 복구 검사를 CI에 추가했습니다. 새 검사 로그는 버전·실행 ID로 구분합니다.

HAL Docs의 서로 다른 장치 예제는 함께 적용·실행됩니다. 같은 장치의 함수 카드는 마지막 선택으로 교체되며, 필요한 선행 코드는 함께 들어갑니다. 여러 예제의 `HAL_Delay`는 전체 반응 주기에 영향을 줍니다. 이번 버전에서 카드 누적 선택이나 병렬 실행 기능을 추가한 것은 아닙니다.

배포 전 개발 소스 검사: 단위 406개, PIN UI 362개 시나리오와 실제 HAL 실행 342건, Docs 다중 적용 UI 3개 시나리오/실행 6건, 독립 조합·충돌 검사 7개 통과. 버전 상승 전 개발 소스 증거와 배포 후 공개 EXE 검증은 구분합니다.
