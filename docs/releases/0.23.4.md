# STM Simulator 0.23.4

- 요청한 디버그 보조 버튼, 기본 크기 버튼/설명, 코드 상단 실행 범위 문구/찾기·바꾸기 버튼, 배선 버튼, 패널 이동 드롭다운을 제거했습니다.
- F6 일시정지, F10 한 줄 실행, F11 함수 안으로, Shift+F11 함수 밖으로, Shift+F5 정지, Ctrl+Shift+F5 디버그 시작을 제공합니다. 모달/입력 조합이 충돌하지 않도록 처리했습니다.
- 찾기/바꾸기는 Ctrl+F/Ctrl+R, 배선은 W, 선택은 V로 유지합니다. 선택한 장치는 Alt+0으로 기본 크기를 복원합니다. 패널 제목 드래그와 제목 우클릭/Shift+F10의 위치 선택으로 패널을 이동합니다.
- **보드 구성 초기화**를 왼쪽 회로 구성에 추가했습니다. 부품·배선·보드/빵판 배치·핀/주변장치 설정을 초기화하며 코드와 다른 소스 파일은 유지합니다. 확인·취소·Esc·되돌리기·다시 실행을 지원하며 실행 중에는 사용할 수 없습니다. 코드 초기화는 별도로 유지합니다.

검증: 단위/모델 검사 312개, 격리된 앱의 회로/코드 보존 및 undo/redo/재시작, 실제 시뮬레이터 및 Windows GDB의 단축키 단계 실행, Dark/White 화면을 확인했습니다. 물리 STM32 보드 실행 검사는 아닙니다. 공개 EXE에서도 초기화/단축키/실제 GDB 단계 실행을 확인했습니다. [검증 보고서](https://github.com/moonsyu/STM-Simulator/blob/main/docs/audits/0.23.4-controls/REPORT.md).

다운로드 실행 파일은 **STM-Simulator.exe**입니다. ZIP, SHA256.txt, BUILD-INFO.json, update-manifest.json을 함께 제공합니다.
