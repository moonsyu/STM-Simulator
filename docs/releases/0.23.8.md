# STM Simulator v0.23.8

## 주요 변경 사항
- **워크벤치 전반 UI/UX 밀도 및 레이아웃 최적화**
  - 상단바(`.topbar`), 실행·디버그 툴바(`.ide-toolbar`), 도크 패널 헤더(`.dock-heading`), 탭바(`.panel-tabs`, `.source-tabs`), 하단 모니터 헤더 및 스트립의 수직 여백을 정돈하여 코드 편집기와 회로 캔버스의 실사용 작업 영역을 확대했습니다.
  - 좌측 `프로젝트 · 부품` 패널을 플렉스 컬럼 구조로 개편하여 이중 스크롤바를 제거하고 데스크톱 화면에서 한눈에 보이는 부품 카드 수를 대폭 늘렸습니다.
  - 긴 프로젝트 폴더 경로(`#workspace-path`)를 최대 2줄 말줄임 및 호버 툴팁(`title`)으로 표시하여 `1024×640` 소형 화면에서도 하단 부품 검색 영역이 가려지지 않도록 개선했습니다.
- **텍스트 표기 및 세부 정보 가독성 개선**
  - `장치 Docs` 탭 상단 헤더에서 장치명과 부제목이 동일할 때 중복 출력되던 현상을 수정하여 접점 수와 부품 ID(`N개 접점 · partId`)가 명확히 표시되도록 개선하고, 핀 연결표 및 함수 카드 스타일을 정돈했습니다.
  - 코드 편집기 상단 파일 선택 드롭다운에 `편집 파일` 문맥 레이블을 추가하고, `실행 환경` 툴바(`.firmware-tools`)를 인라인 플렉스 구조로 정돈했습니다.
  - 좌측 사이드바의 HAL 예제 검색창(`#hal-example-search`) 및 예제 선택 드롭다운(`#hal-example`)의 폰트·우측 패딩을 조정하여 텍스트 잘림 현상을 해소했습니다.
