# 장치 카탈로그 적용 범위

2026-10-15 · 로컬 0.19.0

조사 항목 80개(보드·빵판 포함)의 외형·접점·HAL 예제·Docs를 연결했습니다. 기존 학습 부품 35종을 보존하여 부품 메뉴는 113항목, HAL 예제는 120개입니다. 원본 사진을 배포하지 않고 참고 외형으로 SVG를 작성했습니다. 크기·간격은 빵판 배치를 위한 학습용 비율이며 제조 도면이나 모든 판매 리비전의 핀 배치를 보장하지 않습니다.

[모형 확인](device-model-gallery.html) · [Docs 사용법과 기능 한계](DEVICE-DOCS.md)

회로 실행은 아래 기본 예제의 구현 범위입니다. 80개 기본 예제는 실제 ARM 명령 실행 없이 지원 HAL 호출과 신호/통신 모델로 동작합니다. CAN은 내부 루프백, 카메라는 식별 레지스터, SD는 초기화까지입니다. 모든 80개 예제와 main.c 삽입 결과의 ARM 컴파일·링크를 검사했습니다. 실물 보드 실행 검사는 아닙니다.
