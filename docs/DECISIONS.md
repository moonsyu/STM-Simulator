# 결정 기록

## 2026-10-16 · Docs GPIO 함수 적용과 파일 진단

- 상황: LED의 WritePin 카드가 초기화용 RESET 호출만 미리 보기에 표시하고 실제 main 반복 영역을 비워 둠. 기존 검사는 함수/파일 추가 여부와 컴파일 중심이라 출력 동작을 놓침.
- 결정: GPIO 출력 함수의 명시적 main 예제를 제공하고 실제 LED 전류·점등을 검사. 미리 보기와 삽입의 동일 결과를 검증. 기존 사용자 코드와 정상 배선을 보존하고 누락 GND를 재연결.
- 진단: 사용자의 요청에 따라 실행 로그와 최근 자동 저장 회로 사본을 앱의 로컬 프로필에 보관. 외부 전송하지 않으며 로그 크기를 제한. 기존 버전은 화면 로그만 제공하므로 이번 진단은 Chromium Local Storage의 읽기 전용 사본을 사용.
- 범위: 기존 UI 구조 유지. 사용자 앱/회로는 직접 수정하지 않고 별도 테스트 회로에서 검증.

## 2026-10-17 · 전체 Docs 실행 감사

- 요청: 모든 장치의 Docs 코드 적용과 자동 배선을 실제 실행 로그로 검사.
- 방법: 114개 라이브러리 항목에 실제 신규 배치 기본값을 적용. 입력 변경, 출력 상태, 통신 응답, 표시 메모리, 기계 동작을 기록. 원본 예제와 main 삽입본 비교. 697개 단선 복구와 전체 누락/오접속 복구 후 재실행.
- 판정: 컴파일 성공과 HAL 호출 도달은 장치 기능 통과와 구분. 기존 예제 자체가 틀리면 그 예제와 토폴로지가 같아도 정상 판정하지 않음. Bare-metal은 HAL 실행기에서 실행 불가로 별도 표시.
- 범위: 테스트·보고서만 추가하고 생산 코드 및 사용자 프로필은 보존. 공개 0.23.1 EXE는 숨김 창과 별도 프로필에서 검사. 결함 위치는 보고서에 따로 저장.
