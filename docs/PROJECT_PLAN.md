- 승인 근거: 사용자의 명시적 문서 적용 요청을 이 한정된 UI/기능 명세의 구현 승인으로 기록합니다. 일치하는 UI 계획/시안을 먼저 보존하고 작업 중 구조 변경은 하지 않습니다.
- 위험: 마키/Esc 우선순위, 모달·에디터 단축키 침범, 부유/정지 오표시, 빵판 캐시 무효화 누락. 단위 검사와 격리 Electron 입력·DOM 동일성·측정 로그로 검증합니다.
- 완료 기준: 전체 단위 검사, 문서의 52상태 대비/핵심 스모크, 신규 동작 검사, Windows CI 및 0.24.0 공개 5개 자산/실행/업데이트 검증.
