# 저작권·상표 및 저장소 공개 범위 검토

검토일: 2026-09-06. 대상: STM Emulator 0.3.2 소스, 개발 참고 자료, Windows 배포 구성.

## 결정: Private

참고 사진·핀맵의 재배포 권한과 보드 외관을 참고한 그림의 권리 관계를 확인하지 못했습니다. 따라서 이번 업로드는 **Private**으로 제한합니다. 이는 침해가 확정되었다는 판단이나 포괄적인 법률 검토 결과가 아닙니다. Private 설정은 접근 범위를 제한할 뿐, 제3자 저작물을 사용할 권한을 부여하지 않습니다.

## Public 전환 전 남은 확인

원본 사진·핀맵과 보드 외관 표현의 권리 관계를 확인하거나, 그에 의존하지 않는 그림으로 교체한 뒤 공개 범위를 다시 검토해야 합니다. 제외된 자료는 허락 확인 없이 재추가하지 않습니다. 소스 공개·재배포 라이선스는 소유자가 별도로 결정해야 하며 이번 작업에서 임의의 오픈소스 라이선스를 부여하지 않았습니다.

STM Emulator는 STMicroelectronics의 공식 제품이 아니며, ST의 후원·승인·제휴를 주장하지 않습니다. STM32, NUCLEO 및 ST 관련 상표는 각 권리자의 자산입니다.
